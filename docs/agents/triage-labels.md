# Triage labels

The canonical triage roles map directly to these GitHub labels:

| Role | Label |
| --- | --- |
| Maintainer evaluation required | `needs-triage` |
| Waiting for reporter information | `needs-info` |
| Ready for an autonomous agent | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |
